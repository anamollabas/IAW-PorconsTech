# Context

PorçonsTech acaba d'iniciar la seua activitat.

L'empresa necessita disposar d'un primer servidor corporatiu que servirà de base per allotjar totes les aplicacions web que s'implantaran durant els pròxims mesos.

Com a membre del Departament d'Infraestructura, la teua primera responsabilitat serà desplegar aquest servidor seguint les especificacions indicades.

---

# Objectiu

Implantar un servidor Ubuntu a AWS capaç d'allotjar aplicacions web.

Al final d'aquesta Ordre de Treball hauràs de disposar de:

- Ubuntu Server
- Apache
- PHP
- MariaDB
- VirtualHost
- HTTPS
- Aplicació PHP desplegada

---

# Sprints

- Sprint 0 - Preparació de l'entorn AWS
- Sprint 1 - Instal·lació d'Apache
- Sprint 2 - Configuració de VirtualHost
- Sprint 3 - Instal·lació de PHP
- Sprint 4 - Instal·lació de MariaDB
- Sprint 5 - Desplegament de l'aplicació
- Sprint 6 - Configuració d'HTTPS
