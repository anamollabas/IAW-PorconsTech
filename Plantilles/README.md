# 📚 Plantilles de PorçonsTech

Aquesta carpeta conté les plantilles utilitzades per construir totes les Ordres de Treball (OT) del curs.

No està destinada a l'alumnat.

## Contingut

- Plantilla README d'una OT
- Plantilla d'Sprint
- Plantilla de lliurables
- Plantilla de rúbrica
- Plantilla d'informe final

Quan es cree una nova OT, simplement es copiaran aquestes plantilles i s'adaptaran al projecte corresponent.
