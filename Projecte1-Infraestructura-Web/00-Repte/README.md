# Context del projecte

## Benvingut/da al Departament d'Infraestructures de PorçonsTech

PorçonsTech és una empresa tecnològica que acaba d'iniciar la seua activitat.

L'empresa necessita publicar diferents aplicacions web durant els pròxims mesos, però encara no disposa de cap infraestructura.

Com a membre del Departament d'Infraestructures, la teua primera missió consisteix a preparar un servidor web que servisca de base per a tots els projectes de l'empresa.

Durant aquesta Ordre de Treball construiràs una infraestructura basada en una pila **LAMP (Linux, Apache, MariaDB i PHP)** i la protegiràs mitjançant **HTTPS**.

Aquesta infraestructura serà reutilitzada en totes les següents Ordres de Treball del curs.

---

## El teu repte

Al final d'aquesta OT hauràs de ser capaç de demostrar que:

- el servidor web funciona correctament;
- PHP està operatiu;
- MariaDB funciona correctament;
- el lloc web és accessible mitjançant HTTPS;
- tota la infraestructura ha quedat documentada.

Quan finalitzes aquesta OT, PorçonsTech disposarà del seu primer servidor de producció.
