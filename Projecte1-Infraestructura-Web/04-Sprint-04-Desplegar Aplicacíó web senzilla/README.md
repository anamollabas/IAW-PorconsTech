# Sprint 2 - Construcció de la infraestructura LAMP

## 🎯 Objectiu

En aquest Sprint desplegaràs la primera infraestructura de PorçonsTech.

Treballaràs amb una arquitectura formada per un únic servidor on s'instal·laran tots els serveis necessaris per executar aplicacions web.

En finalitzar aquest Sprint disposaràs d'un servidor amb:

- Ubuntu Server
- Apache
- MariaDB
- PHP

---

## 📋 Requisits previs

Abans de començar has de:

- Haver completat el Sprint 1.
- Disposar d'un compte d'AWS Academy.
- Poder accedir al Campus Virtual.
- Tindre accés al teu repositori de GitHub.

---

## 🏗️ Arquitectura del projecte

En aquesta primera Ordre de Treball utilitzarem una arquitectura formada per un únic servidor.

En aquest servidor s'executaran tots els serveis:

- servidor web;
- base de dades;
- intèrpret PHP.

És una arquitectura molt senzilla i adequada per començar.

Més endavant evolucionarem aquesta infraestructura cap a arquitectures de dos nivells, tres nivells i alta disponibilitat.

---

## 📋 Tasques

Durant aquest Sprint hauràs de:

1. Crear una instància EC2.
2. Configurar els grups de seguretat.
3. Assignar una IP elàstica.
4. Connectar-te mitjançant SSH.
5. Instal·lar la pila LAMP.
6. Comprovar que el servidor funciona correctament.

---

## 🛠️ Desenvolupament

Segueix els passos indicats per la professora durant la sessió i completa totes les tasques proposades.

Cada vegada que finalitzes un apartat comprova que el servidor continua funcionant abans de passar al següent.
