# Criteris d'avaluació

Durant aquest projecte es valorarà especialment:

## Desenvolupament del projecte

- Configura correctament la infraestructura.
- Instal·la els components necessaris.
- Verifica el funcionament dels serveis.
- Documenta totes les actuacions.
- Manté un repositori ordenat.

---

## Technical Review

La prova objectiva valorarà la capacitat de:

- Comprendre els conceptes treballats.
- Interpretar configuracions.
- Diagnosticar errors.
- Justificar decisions tècniques.
- Aplicar els coneixements a situacions semblants.

No es valorarà la memorització de comandes sinó la comprensió del seu funcionament.
