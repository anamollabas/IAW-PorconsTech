# 🏢 El repte · Portal corporatiu de PorçonsTech

PorçonsTech necessita un portal corporatiu que puga créixer amb l'empresa.

La direcció no vol un lloc format per pàgines HTML que s'hagen de modificar manualment cada vegada que canvia un contingut.

Necessita una plataforma que permeta:

- publicar continguts;
- gestionar usuaris;
- ampliar funcionalitats;
- fer còpies de seguretat;
- actualitzar el sistema;
- consultar informació d'accés;
- personalitzar l'aparença;
- incorporar funcionalitats pròpies.

---

# 🎯 La missió

La solució seleccionada serà **WordPress**.

Durant el projecte el portal passarà per tres fases:

```text
IMPLANTAR
   ↓
ADMINISTRAR
   ↓
ADAPTAR
```

## Fase 1 · Implantació

Instal·laràs i publicaràs WordPress sobre la infraestructura de PorçonsTech.

## Fase 2 · Administració

Gestionaràs WordPress mitjançant WP-CLI i realitzaràs tasques reals d'administració.

## Fase 3 · Adaptació

Crearàs una personalització pròpia de PorçonsTech modificant l'aparença i incorporant una funcionalitat mínima mitjançant codi.

---

# ✅ Producte final

En acabar, PorçonsTech haurà de disposar d'un portal:

- funcional;
- segur;
- administrable;
- actualitzable;
- recuperable;
- personalitzat;
- amb una adaptació pròpia verificada i documentada.
