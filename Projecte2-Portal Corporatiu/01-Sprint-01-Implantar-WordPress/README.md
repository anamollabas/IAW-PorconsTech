# 🚀 Sprint 1 · Implantar WordPress

> [!IMPORTANT]
> **Duració estimada:** 10 hores  
> **Projecte:** Portal Corporatiu amb WordPress  
> **Resultat d'Aprenentatge principal:** RA2 · Implantació de gestors de continguts

---

# 🎯 Objectiu

En aquest Sprint implantaràs **WordPress** sobre la infraestructura creada al **Projecte 1**.

Al final hauràs desplegat un gestor de continguts completament funcional, preparat per començar a crear i administrar un lloc web professional.

---

# 📚 Context

PorçonsTech ja disposa d'una infraestructura web operativa.

Ara és el moment de publicar la seua primera pàgina web corporativa.

Com a administrador de sistemes hauràs de:

- preparar la base de dades;
- descarregar WordPress;
- configurar el CMS;
- verificar que funciona correctament;
- deixar-lo preparat per a la seua administració.

---

# 🛠 Què aprendràs?

En aquest Sprint aprendràs a:

- Comprendre què és un CMS i quina és la seua utilitat.
- Implantar WordPress sobre una infraestructura LAMP.
- Configurar correctament el fitxer `wp-config.php`.
- Configurar els paràmetres bàsics del lloc web.
- Aplicar les primeres mesures de seguretat.
- Publicar un gestor de continguts funcional.

---

# 📋 Activitats

Durant aquest Sprint realitzaràs les següents activitats:

1. Instal·lació de WordPress.
2. Configuració de la base de dades.
3. Configuració inicial del CMS.
4. Verificació del funcionament.
5. Documentació del procés.

---

# 📦 Producte final

En finalitzar aquest Sprint hauràs d'entregar:

- WordPress instal·lat i operatiu.
- Base de dades configurada.
- Captures de les principals fases de la instal·lació.
- Documentació actualitzada al repositori GitHub.

---

# 📸 Evidències

Durant el desenvolupament hauràs de recopilar les captures indicades en la pràctica.

Aquestes evidències formaran part de la documentació del projecte.

---

# ✅ Checklist

Abans de continuar comprova que:

- [ ] WordPress funciona correctament.
- [ ] La base de dades està connectada.
- [ ] El lloc web és accessible des del navegador.
- [ ] La configuració inicial està completada.
- [ ] El repositori GitHub està actualitzat.

---

# ➡️ Quan acabes

Quan completes aquest Sprint podràs continuar amb el **Sprint 2 · Administrar WordPress**, on aprendràs a gestionar el CMS mitjançant **WP-CLI**, administrar usuaris, temes, plugins i realitzar tasques de manteniment professional.
