# 🚀 Sprint 2 · Administrar WordPress

> [!IMPORTANT]
> **Duració estimada:** 10 hores  
> **Projecte:** Portal Corporatiu amb WordPress  
> **Resultat d'Aprenentatge principal:** RA3 · Administració de gestors de continguts

> [!NOTE]
> Aquest Sprint està basat en la pràctica **WP-CLI** de **José Juan Sánchez**, adaptada a la metodologia **PorçonsTech**.

---

# 🎯 Objectiu

En aquest Sprint aprendràs a administrar WordPress com ho faria un administrador de sistemes professional.

Utilitzaràs **WP-CLI** per automatitzar tasques d'administració, gestionar usuaris, temes, plugins i mantenir el gestor de continguts actualitzat.

---

# 📚 Context

La pàgina web corporativa de PorçonsTech ja està publicada.

Ara l'empresa necessita que el sistema siga fàcil de mantenir, segur i eficient.

Com a administrador hauràs de realitzar les tasques habituals de manteniment i administració del CMS.

---

# 🛠 Què aprendràs?

En aquest Sprint aprendràs a:

- Instal·lar i configurar WP-CLI.
- Administrar WordPress des del terminal.
- Gestionar usuaris i rols.
- Instal·lar i administrar temes.
- Instal·lar i administrar plugins.
- Actualitzar WordPress de forma segura.
- Realitzar tasques bàsiques de manteniment.
- Automatitzar processos repetitius.

---

# 📋 Activitats

Durant aquest Sprint realitzaràs les següents activitats:

1. Instal·lació de WP-CLI.
2. Administració de WordPress des del terminal.
3. Gestió d'usuaris.
4. Gestió de temes.
5. Gestió de plugins.
6. Actualització del CMS.
7. Tasques de manteniment.

---

# 📦 Producte final

En finalitzar aquest Sprint hauràs d'entregar:

- WordPress administrat mitjançant WP-CLI.
- Plugins i temes configurats.
- Usuaris creats amb diferents rols.
- Sistema actualitzat.
- Documentació actualitzada al repositori GitHub.
