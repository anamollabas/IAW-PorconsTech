# 🏢 El repte · La plataforma col·laborativa de PorçonsTech

PorçonsTech està creixent.

Fins ara hem desplegat la infraestructura web de l'empresa i hem creat el seu portal corporatiu amb WordPress.

Però apareix una nova necessitat.

Els treballadors de PorçonsTech comparteixen constantment:

- documents;
- informes;
- imatges;
- fitxers de projectes;
- documentació interna.

Enviar els fitxers per correu o mantindre múltiples còpies genera problemes:

- versions diferents del mateix document;
- dificultat per controlar els accessos;
- informació dispersa;
- poca traçabilitat;
- dificultat per treballar conjuntament.

---

# 🎯 La necessitat

La direcció de PorçonsTech vol implantar una **plataforma col·laborativa pròpia**.

La plataforma haurà de permetre:

- disposar d'un espai centralitzat de fitxers;
- crear diferents usuaris;
- controlar els permisos d'accés;
- compartir recursos;
- treballar de forma cooperativa.

---

# ☁️ La solució

La solució seleccionada és:

## Nextcloud

Nextcloud és una plataforma web que permet gestionar fitxers i recursos compartits des d'un navegador.

Durant aquest projecte hauràs d'implantar-la i preparar-la per al seu ús dins de PorçonsTech.

---

# 👥 Organització inicial

Com a mínim hauràs de disposar de diferents usuaris de prova.

Per exemple:

- `admin`
- `anna`
- `marc`
- `laura`

També podràs crear algun grup relacionat amb l'empresa.

Per exemple:

- `administracio`
- `tecnics`
- `projectes`

---

# 📁 Cas de treball

PorçonsTech necessita un espai compartit per a un projecte intern.

Crearàs un espai o carpeta:

`Projecte PorçonsTech`

Dins d'aquest espai hauràs de demostrar que:

- diferents usuaris poden accedir-hi;
- els permisos poden ser diferents;
- es poden compartir fitxers;
- els canvis són visibles per als usuaris autoritzats;
- un usuari sense permís no pot realitzar les mateixes accions.

---

# ✅ Missió

En acabar hauràs de demostrar que PorçonsTech disposa d'una plataforma col·laborativa funcional.

No necessitem una instal·lació avançada.

L'objectiu és demostrar que eres capaç de:

**implantar → configurar → gestionar usuaris → protegir recursos → compartir → comprovar.**
