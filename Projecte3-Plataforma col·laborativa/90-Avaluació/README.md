# 📊 Avaluació · Projecte 3 · Plataforma col·laborativa

## Resultat d'aprenentatge

Aquest projecte treballa el **RA4**:

> Gestiona aplicacions d'ofimàtica web integrant funcionalitats i assegurant l'accés a la informació.

En aquest projecte es treballen específicament els criteris:

- **RA4.a** · Utilitat de les aplicacions d'ofimàtica web.
- **RA4.b** · Classificació segons funcionalitat i prestacions.
- **RA4.c** · Instal·lació d'aplicacions d'ofimàtica web.
- **RA4.e** · Gestió de comptes d'usuari.
- **RA4.f** · Seguretat en l'accés dels usuaris.
- **RA4.g** · Ús cooperatiu de les aplicacions.
- **RA4.h** · Documentació d'ús i gestió.

> El **RA4.d** no s'avalua específicament en aquest projecte perquè no s'ha implantat una intranet pròpiament dita.

# 🧮 Qualificació del projecte

| Instrument | Pes |
|---|---:|
| Sprint 1 · Implantar Nextcloud | 40 % |
| Technical Review | 60 % |

## Sprint 1

S'avaluarà mitjançant una rúbrica de **10 criteris**.

Cada criteri tindrà tres nivells:

- **2 punts · Assolit**
- **1 punt · Parcialment assolit**
- **0 punts · No assolit**

La rúbrica suma un màxim de **20 punts**, que Moodle convertirà a la qualificació configurada per a l'activitat.

## Technical Review

La Technical Review serà:

- individual;
- realitzada en Moodle;
- sense ús d'Intel·ligència Artificial;
- basada únicament en procediments i situacions treballades durant el Sprint.

Per superar el projecte serà necessari obtindre almenys **4/10 en la Technical Review**.
