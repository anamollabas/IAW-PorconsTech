# 🧩 Sprint 3 · Evolució de l'aplicació PHP + MySQL

## 🎯 Objectiu

En els Sprints anteriors has desplegat una aplicació PHP + MySQL de dues formes:

```text
Sprint 1 · EC2 WEB + EC2 MySQL
Sprint 2 · Docker Compose
```

Ara treballarem sobre **la mateixa aplicació del Sprint 2**.

No crearàs una aplicació nova des de zero. Faràs modificacions petites i guiades per entendre com funciona PHP al servidor i completaràs les funcionalitats necessàries del projecte.

## ⏱️ Duració orientativa

**3-4 hores**

## 📚 Resultats d'aprenentatge

Aquest Sprint completa principalment:

- **RA5.a-i** · PHP, HTML, sintaxi, control, funcions, formularis, sessions, autenticació i aïllament d'usuaris.
- **RA6.d** · Creació d'una base de dades i una taula des de PHP.

També reforça:

- **RA6.e** · CRUD.
- **RA6.f** · Seguretat d'accés.
- **RA6.g** · Comprovació de funcionament i rendiment.

## 🧭 Ordre de treball

1. Comprovar que el Sprint 2 continua funcionant.
2. Identificar PHP com a llenguatge de servidor.
3. Crear una pàgina PHP molt senzilla.
4. Afegir un formulari de login.
5. Utilitzar funcions i estructures de control.
6. Mantindre l'usuari entre pàgines amb sessions.
7. Protegir una pàgina.
8. Comprovar dues sessions independents.
9. Crear una BD i una taula des de PHP.
10. Retirar el privilegi temporal de creació.
11. Verificar que el CRUD original continua funcionant.
12. Fer una comprovació bàsica de rendiment.

> ⚠️ No avances si una comprovació falla.
