# 🌐 Projecte 1 · Infraestructura Web

> [!IMPORTANT]
> **Client:** PorçonsTech  
> **Departament:** Infraestructura  
> **Duració:** 18 hores (aprox.)  
> **Resultat d'Aprenentatge principal:** RA1 - Preparació de l'entorn de desenvolupament i dels servidors d'aplicacions web.

---

# 🎯 Repte

PorçonsTech acaba de crear una nova empresa tecnològica i necessita desplegar la seua primera infraestructura web al núvol.

Com a membre del departament d'infraestructura, la teua missió serà preparar un servidor al núvol, instal·lar tots els serveis necessaris i publicar una aplicació web de forma segura perquè qualsevol usuari puga accedir-hi a través d'Internet.

Al final del projecte hauràs creat una infraestructura molt semblant a la que utilitzen milers d'empreses cada dia.

---

# 📦 Producte final

En finalitzar aquest projecte hauràs desplegat una infraestructura formada per:

- Una instància EC2 a Amazon Web Services.
- Un servidor Apache.
- PHP configurat correctament.
- MariaDB operativa.
- Una aplicació web desplegada.
- Accés segur mitjançant HTTPS.
- Un repositori GitHub documentat amb tot el procés.

---

# 🛠 Tecnologies

Durant aquest projecte treballarem amb:

# 📁 Estructura del projecte

Aquest projecte està dividit en quatre Sprints.

| Sprint | Objectiu |
|---------|----------|
| Sprint 0 | Preparar l'entorn de treball |
| Sprint 1 | Desplegar una infraestructura LAMP |
| Sprint 2 | Implantar una aplicació web |
| Sprint 3 | Protegir la infraestructura amb HTTPS |

Cada Sprint està format per diferents passos que hauràs de completar abans de continuar amb el següent.

---

# 📚 Abans de començar

- Linux

- Xarxes
- Git

No és necessari haver treballat prèviament amb AWS.

# 📋 Avaluació

L'avaluació del projecte es basa en dues evidències complementàries.

## 📦 Desenvolupament del projecte (40%)

Es valorarà:

- Funcionament de la infraestructura.
- Organització del repositori GitHub.
- Documentació dels diferents Sprints.
- Compliment dels requisits del projecte.
- Bones pràctiques durant el desenvolupament.

L'ús d'eines d'Intel·ligència Artificial està permés durant el desenvolupament del projecte.

---

## 🧠 Technical Review (60%)

Una vegada finalitzat el projecte realitzaràs una **Technical Review** individual a Moodle.

La prova estarà formada per preguntes relacionades exclusivament amb aquest projecte.

No es valorarà la memorització de comandes, sinó la teua capacitat per:

- Comprendre el funcionament dels diferents components.
- Interpretar configuracions.
- Diagnosticar incidències.
- Justificar les decisions tècniques adoptades.
- Aplicar els coneixements adquirits a situacions semblants.

Per superar el projecte serà necessari obtenir almenys **4 punts sobre 10** en aquesta prova.
