# Material del professor

Aquesta carpeta conté les plantilles i documents base utilitzats per construir totes les Ordres de Treball del curs.

L'alumnat no necessita utilitzar aquest material.

## Plantilles disponibles

- README d'una OT
- Sprint
- Lliurables
- Rúbrica
- Informe final

Quan es cree una nova OT simplement es copiaran aquestes plantilles.
